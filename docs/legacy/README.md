# Legacy C renderer

The original Buddhabrot renderer in C (version 2.x), kept for its history. It
is not built and the commit hook does not check it. It was a client and server
over sockets (`buddha-server.c`, `buddha-com.c`), built with SCons
(`Sconstruct`) and launched by `launch.sh`. Comments are in Italian.

It was added to the repository in 2014 (`4369ddb`) and moved here from
`legacy/` in October 2026.
